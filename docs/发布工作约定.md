# 发布工作约定（老韩确认，2026-11-27）

适用范围：本 monorepo（dsh-mod-sel）内全部自研插件。

1. **每次修复或功能完成后**：
   - 先**询问老韩是否推送到 git**，确认后再 push；不擅自推送。
   - **每次修复递增版本号**（package.json 的 version）：
     - 修 bug → 升 patch（如 0.3.0 → 0.3.1）
     - 加功能 → 升 minor（如 0.3.0 → 0.4.0）
   - 推送后同步执行 `node scripts/build-index.mjs` 刷新 `index.json` 的 source.commit 并提交推送。
2. 一次改动涉及多个插件时，各插件版本号独立递增，只动改过的那个。
