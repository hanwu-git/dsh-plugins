统一模型中心 · 原型 v1.0

替代各连接器自己插进输入框的胶囊，改由 DSH 独立插件统一接管。

交互设计

  1. 横排连接标签：Loomy / Trae / WorkBuddy / Qoder / 豆包，鼠标悬停即切换下方列表
  2. 自动频率排序：按最近选用次数自动置顶「常用」区，无需手动
  3. 替换原选择器：左下角胶囊改为统一触发器
  4. 信息密度：倍率 / 上下文 / 免费标记 / 思考等级 四类徽标

为什么这样能不被冲掉

新插件只读各连接器公开的 status 路由（/plugins/*/usage），不往连接器里插代码。连接器升级只会改它自己的路由，我的 UI 不受影响。

试用

  • 鼠标移到顶部标签 → 列表切换
  • 点「刷新」模拟使用次数变化 → 常用区重排
  • 搜索框可跨连接器过滤

数据取自你本机 5 个连接器实时接口。
