# 输入框按钮组 更新日志

## 0.2.0 (2026-11-28)
- 修复：重启确认弹窗点击"重启"后立即关闭并锁定按钮，杜绝二次点击触发第二次强杀。
- 修复：确认弹窗"重启"主按钮改用固定配色（深蓝底白字），不再依赖主题令牌——原令牌在该上下文解析为近白底色，白底白字不可读。
- 修复：设置页"输入框按钮"选项卡空白——订阅机制改为与按钮行相同的 useState+useEffect 模式，外层加错误边界（卡片异常时显示错误信息并写入诊断日志）。
- 修复：设置卡开关配色固定为蓝色（开）/灰色（关），主题令牌在深色主题下解析为白底导致状态不可见。
- 增强：重启助手 stderr 从丢弃改为捕获落诊断日志，并监听 spawn-error/exit 事件，执行链全程可追溯。
- 增强：重启确认后 8 秒自动刷新页面，跟进新实例地址（DSH 每次重启随机换端口）。
- 变更：Config 改用宿主 schema 库声明（z.object），这是设置系统收录插件配置页的硬条件；配套声明 peerDependencies @deepseek-ai/schemastery。

## 0.1.0 (2026-11-27)
- 初始版本：合并 prompt-polish（润色/重写）与 dsh-quick-actions（刷新/重启）为输入框下的一行按钮组，解决两插件各自占行、按钮错行的问题。
- 设置卡片：每个按钮可开关显示、可编辑自定义说明（追加到悬停提示）。
