# 统一模型中心 / Unified Model Center

把所有已连接平台（Loomy / Trae / WorkBuddy / Qoder / 豆包）的模型集中到一个选择器里。

## 它解决什么问题

过去每个连接器都往输入框里插自己的状态胶囊，并把模型入口嵌在自己的插件里。连接器一升级，写在里面的定制代码就全部失效。

本插件把界面**完全独立**出来：它只读取各连接器公开的状态接口（`/plugins/*/usage`、`/status`、`/catalog`），不修改、不嵌入任何连接器插件。连接器升级不会改变本插件的界面。

## 功能

- 顶部横排连接标签，鼠标悬停即切换下方模型列表
- 每个连接各自维护「常用」区（按使用频率自动排序，最多 3 个），不跨连接混排
- 全部模型列表与常用区**不去重**
- 模型行展示倍率、上下文长度、免费/限免、思考档位、生图标记
- 跨连接搜索
- 弹窗尺寸固定 560×470，模型多少都不跳动
- 点击模型即通过宿主 `modelDirectories.select()` 真正切换当前会话模型

## 使用

设置 → 插件 中启用本插件后，输入框工具行会出现一个「统一模型中心」胶囊（替代原来的模型选择器）。点击即可打开。

模型切换调用的是 DSH 官方的会话模型选择 API，与原生选择器完全等价，下一次请求立即使用新模型。
